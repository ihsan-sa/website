# website goals

The owner's standing goals come first, in his own words, with where he said them so a run can read them back from
Slack. No run edits that section; a change to it goes to him as a pull request he merges. Below it, runs keep the goals
they propose and the record of what closed. This repo is ihsan.cc, his public personal site, so whatever a run changes
is seen by people outside the box.
